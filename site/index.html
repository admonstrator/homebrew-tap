admonstrator / homebrew-tap

A small Homebrew tap

CLI tools and apps I've built, packaged for Homebrew and kept in one place.

$ brew tap admonstrator/tap
$ brew trust admonstrator/tap
$ brew install lagerregal

The trust step tells Homebrew you're okay loading formulae from this non-official tap — do it once, right after tapping.

How it works

  • 1

    Tap it. brew tap admonstrator/tap adds this repository as a source of formulae, alongside Homebrew's official ones.

  • 2

    Trust it. Since this isn't an official Homebrew tap, brew trust is your explicit go-ahead to load formulae from it.

  • 3

    Install and stay updated. Each formula's real source lives in its own repository; releases there regenerate the recipe here automatically, so brew upgrade just works.

Formulae
