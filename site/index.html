Install in three lines

Add the tap once, tell Homebrew you trust it, and every tool in it is an ordinary brew install from then on.

$ brew tap admonstrator/tap
$ brew trust admonstrator/tap
$ brew install lagerregal mantaray

How it works

🫗

Tap it

brew tap adds this repository as a source of formulae, right alongside Homebrew's official ones.

🤝

Trust it

This isn't an official Homebrew tap, so brew trust is your explicit one-time go-ahead to load formulae from it.

🔄

Stay updated

Each tool's source lives in its own repository; releases there regenerate the formula here automatically, so brew upgrade just works.
