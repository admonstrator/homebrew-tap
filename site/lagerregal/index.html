lagerregal · German for “storage shelf”

Every package
in its place.

A CLI and TUI that classifies, searches and manages your installed Homebrew packages by category — so you finally know what all that stuff is.

Install View source

What it does

Homebrew tells you what's installed. lagerregal tells you what it all is — and helps you keep it tidy.

🗂️

Automatic categories

scan classifies every installed package — Development Tools, Networking, Security, Monitoring and many more — with no setup.

🖥️

Interactive TUI

Run lagerregal with no arguments for a full dashboard: browse by category, inspect dependencies both ways, act on packages — keyboard-first, with full mouse support.

🔎

Search everywhere

/ searches every category at once — no matter where a package is filed. Hits come back grouped under category headings and narrow live with every keystroke.

🚀

Launch from the list

Enter or a double-click opens a cask's app or runs a formula's binary. Everything else — update, note, categorize, uninstall — is one key away in the m action menu.

🧹

Housekeeping

outdated, unmaintained and orphans surface what needs an upgrade, what Homebrew has deprecated, and what nothing depends on anymore.

📌

Update & pin

Update one package, a multi-selection, or everything outdated at once — always with a confirmation first. Pinned formulae are left alone until you unpin them.

📝

Notes & overrides

Attach a personal note to any package with note, or override its category with category when you know better than the classifier.

📸

Snapshots

snapshot saves your installed packages and versions, and compares them later — see exactly what changed between two points in time.

⚡

Fast by default

Results are cached locally and invalidated automatically when packages change, so everyday commands are instant. --refresh forces a re-read.

A closer look

Real screenshots from a live install — Catppuccin Mocha palette, Nerd Font icons per category, and colour spent only where it means something: update status, deprecation, selection.

Also a plain CLI

Every view is a subcommand too — scriptable, with --json where it counts.

$ lagerregal  # no arguments launches the interactive TUI

Install

Via this tap, for macOS and Linux on Apple Silicon, Intel and ARM. Prebuilt binaries — nothing compiles on your machine.

$ brew tap admonstrator/tap
$ brew trust admonstrator/tap
$ brew install lagerregal
