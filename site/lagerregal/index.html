lagerregal · German for “storage shelf”

Every package

What it does

Homebrew tells you what's installed. lagerregal tells you what it all is — and helps you keep it tidy.

🗂️

Automatic categories

scan classifies every installed package — Development Tools, Networking, Security, Monitoring and many more — with no setup.

🖥️

Interactive TUI

Run lagerregal with no arguments for a full dashboard: browse by category, inspect packages, act on them — all from the keyboard.

🧹

Housekeeping

outdated, unmaintained and orphans surface what needs an upgrade, what Homebrew has deprecated, and what nothing depends on anymore.

📝

Notes & overrides

Attach a personal note to any package with note, or override its category with category when you know better than the classifier.

📸

Snapshots

snapshot saves your installed packages and versions, and compares them later — see exactly what changed between two points in time.

⚡

Fast by default

Results are cached locally and invalidated automatically when packages change, so everyday commands are instant. --refresh forces a re-read.

Install

Via this tap, for macOS and Linux on Apple Silicon, Intel and ARM. Prebuilt binaries — nothing compiles on your machine.

$ brew tap admonstrator/tap
$ brew trust admonstrator/tap
$ brew install lagerregal
